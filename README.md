# CARD DUNGEON — 先見の迷宮

敵の5手を先に読み、15枚のカードで運命を覆す、一人称3Dダンジョン・ローグライク。

[ブラウザで遊ぶ](https://card-dungeon.yzgame.chatgpt.site)

## 遊び方

1. 矢印ボタン / WASD / カーソルキーで、1マスずつ迷宮を探索。
2. 敵に遭遇したら、必要に応じてデッキを編集。装備中の15枚のうち交換したいカードを選び、予備のカードをタップ。
3. 敵の5手を見て、自分の5手をセット。「5手を実行」で自動進行。
4. 各カードは戦闘中に1回だけ使用。最大15ターン以内に敵HPを0にし、自分が生存すれば勝利。
5. 勝てば敵のデッキから最大3枚、負けても1枚を獲得。敗北時はカードをすべて保持してB1Fから再挑戦。

防御・反撃は攻撃に、貫通・盾砕きは防御に、回復・集中は敵の隙に合わせる。毒、再生、吸血、奇襲など20種類のカードと高ランク版を収録。

## 迷宮と成長

- B1Fは10マス。1階降りるごとに4マスずつ増加。全マスがつながる不定形の自動生成マップ。
- 深く進むほど敵HPとカードのランクが上昇。5階ごとに守護者が階段を守る。
- 敵4種、宝箱、回復の泉、下り階段、探索済みマップ。
- 勝利でHP20%、階段で35%、泉で一度だけ40%回復。
- 最深層、勝利数、所持カード、デッキ、探索位置、戦闘の配置と途中経過を端末に自動保存。
- メニューからJSONでセーブの書き出し・読み込み。ブラウザや公開先を変える場合はセーブを移行する。

## 実装

`dist/` がそのまま配信できる静的サイト。ビルド・CDN・外部API・APIキー不要。

- `dist/js/engine.js`: UI非依存の迷宮生成・同時解決バトル・報酬・保存検証
- `dist/js/data.js`: カード・敵・成長データ
- `dist/js/app.js`: 日本語UI、タッチ/キーボード操作、保存、5手の自動進行
- `dist/js/scene.js`: Three.js 0.160の3D迷宮。共有ジオメトリとインスタンス描画、DPR制限、30fps上限、非表示時停止。WebGLコンテキスト喪失時は2Dレイキャストへ移行。
- `dist/js/audio.js`: 操作後に有効化できる、Web Audioの短い効果音
- `dist/sw.js`: オフライン用キャッシュ。プレイ中の自動リロードなし

配信先は`dist/`を公開ルートにする。GitHub Pagesなどのサブディレクトリ配信にも相対URLで対応。

## 確認

Node.js 18以降で、追加依存なし。

```sh
npm test
npm run validate
```

テストはマップの連結性、カード相性、毒・集中・回復、同時撃破、15手制限、途中保存再開、報酬、敗北持越し、階層移動、破損セーブを対象とする。

端末の画面比率・safe-areaに対応。ゲーム自体は縦画面を推奨、横画面にも対応。実際のiPhone Safariでの操作感・GPU性能は、公開後の実機確認が必要。

Three.jsのライセンスは `docs/THIRD_PARTY_LICENSES.md`、敵アートの生成プロンプトは `docs/ART_DIRECTION.md` を参照。
