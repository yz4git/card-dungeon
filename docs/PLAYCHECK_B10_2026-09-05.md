## Review

### What works

1. The five-turn forecast system remains strategically meaningful through B10.
2. The persistent-card roguelite loop works: failed runs become stronger and all tested persistent runs eventually reached B10.
3. B5 is a clear milestone and B10 is a genuine climax in difficulty.
4. Healing sources (victory +20%, descent +35%, spring +40%) create recoverable runs without removing danger; detailed B10 finished at only 6 HP before victory recovery.
5. Core combat, save/resume, dungeon generation and card mechanics passed all automated tests.

### Main issues

1. **Deck editing is mandatory but under-communicated.** Never editing the starter deck caused 12/12 runs to stop at B5. The post-battle reward flow returns directly to exploration; it should make newly acquired stronger cards and deck editing more prominent.
2. **B10 repeats the B5 boss identity.** Both use the same Deep Warden definition/deck, only scaled by floor/rank. B10 would feel more climactic with a distinct final form, phase, or move pattern.
3. **Late-game damage growth compresses boss duration.** Detailed B5 took 10 turns, but upgraded cards killed the stronger B10 boss in 5 turns. B10 is dangerous because incoming damage is huge, but it is not necessarily more strategically extended.
4. **Floors 6–10 can feel repetitive.** The game cycles the same five floor labels/themes and uses only three normal enemy definitions plus the Warden boss. Larger layouts (up to 46 cells on B10) increase walking time faster than content variety.
5. **Deck-management friction grows quickly.** A clean B10 run can accumulate roughly 60+ cards from three-card battle rewards plus chests, while only 15 are equipped. On iPhone, repeated one-slot swaps become a significant mid/late-game task.
6. **Difficulty varies strongly by route RNG.** The detailed run had zero battles on B2/B7/B9 but three battles on B8 and B10. Some floors become travel-heavy while others spike abruptly.

## Priority recommendations

1. Make post-victory deck upgrading unmistakable: add `デッキを編集` beside the continue button and highlight newly acquired / higher-rank cards.
2. Give B10 a distinct second phase or final-boss deck instead of only scaling B5 Warden.
3. Add at least 2–3 new normal enemy patterns for B6–B10.
4. Introduce one new dungeon event or visual set in B6–B10 so larger maps add decisions rather than only walking distance.
5. Add a low-friction deck-management aid such as rank sorting, `NEW` markers, compare view, or optional strongest-card auto-equip outside battle.
6. Keep current overall difficulty curve; do not broadly nerf combat. The main improvement should be clarity and late-game variety, not simply lower numbers.
